# 강아지 소재 시장조사 (dog-topic-research)

소재 하나에 대해 **"사람들이 보고 있나(수요) · 말해도 되나(근거) · 남이 이미 했나(경쟁) · 보호자는 어떤 말로 고민하나(언어)"** 네 가지를 한 번에 답하는 스킬이다. 결과는 판단 재료다 — 진행 여부와 최종 선택은 사용자 몫이다(dog-psych-channel 절대 규칙 2 "발산/수렴 분리"와 같다).

이 스킬이 생긴 이유: 이전에는 vidIQ 검색 몇 번을 즉흥으로 돌려 소재를 판단했다. 그러면 ① 방송 클립·카드형 숫자를 롱폼 근거로 오독하고 ② 연구 근거는 대본을 다 쓴 뒤에야 찾아 소재가 뒤늦게 무너지고 ③ 같은 조사를 편마다 다른 방식으로 반복했다. 조사 순서와 판정 기준을 고정해 편 사이 비교가 가능하게 만드는 것이 목적이다.

## 참조 파일

| 파일 | 내용 | 읽는 시점 |
|---|---|---|
| `references/sources.md` | 트랙별 도구·검색어 템플릿·출처 목록(vidIQ 호출 레시피, 논문 DB, 국내 통계) | **조사 시작 시 항상** |
| `references/channel-filters.md` | 채널 규칙 요약(소재 축·재탕·금지 프레임·호칭·해석 층) + 원 규칙 파일 위치 | 종합 판정(5단계) 전 |
| `references/report-template.md` | 리포트 양식(롱폼·쇼츠·카드 분기) | 리포트 작성 시 |
| `references/original-check.md` | **원문 대조** — 네트워크 허용 도메인·사용자 안내(설정 위치)·막히는 사이트 우회·대조 절차·실제 오류 유형 | **조사 시작 전 네트워크 확인** + 대본 완성 뒤 녹음 전 대조 |

연관 스킬의 원 규칙이 이 요약보다 우선한다: `dog-psych-channel`(롱폼), `dog-psych-shorts`(쇼츠·카드), 특히 `dog-psych-channel/references/fact-check-rules.md`와 `dog-psych-shorts/references/04_fact_framing.md`.

## 입력

- **소재 1개** (예: "두 아이 집에서 하면 안 되는 행동").
- **포맷**: 롱폼 / 쇼츠(5블록) / 카드형 / 미정. 말이 없으면 "미정"으로 두고 리포트에서 포맷별 적합도를 함께 낸다 — 묻지 않는다.
- 나머지는 묻지 않는다. 조사 범위는 고정이다: **영상 = 한국어 시장, 연구 = 한국어+영어, 뉴스·통계 = 국내.**

## 작업 흐름

시작할 때 적용 근거 한 줄을 먼저 밝힌다(채널 스킬과 같은 관행). 예:
`적용: 소재=두 아이 집 / 포맷=롱폼 / 영상 KR·연구 KR+EN·통계 KR / 🔍 등급 ON / (dog-topic-research sources.md 반영) — 시장조사 시작합니다.`

### 0. 소재 분해 (1분)

소재를 검색 가능한 단위로 쪼갠다. 이 단계가 허술하면 vidIQ가 정치 뉴스·연애 심리를 섞어 돌려준다(실제로 "강아지 심리 행동"으로 돌렸을 때 결과 40개 중 반려견 영상은 10개 미만이었다).

- **핵심 행동 1개** + **동의어·보호자 입말 3~5개** (예: 다견 차별 → "강아지 차별", "강아지 질투", "끼어드는", "둘째 입양", "다견 가정").
- **연구 키워드(영어)** 3~5개 (예: inequity aversion dogs, jealousy dogs, multi-dog household conflict).
- **배제어**: 고양이·유기견 구조 사연·뉴스 사건 등 소재와 무관한데 섞일 것.

### 0-1. 네트워크 확인 (30초)

`references/original-check.md` §1의 확인 명령을 먼저 돌린다. 학술 사이트가 막혀 있으면 사용자에게 설정 방법을 한 번 안내하고 조사는 그대로 진행하되, 등급은 [초록확인]까지만 준다.

### 1~4. 네 트랙 병렬 조사

서브에이전트(Agent 도구)가 있으면 트랙마다 하나씩 **동시에** 띄운다. 각 에이전트에게 소재 분해 결과, `references/sources.md`의 해당 트랙 절, 산출 양식을 넘긴다. 없으면 순서대로 직접 한다. 세부 도구·검색어는 `sources.md`.

| 트랙 | 핵심 질문 | 산출 |
|---|---|---|
| ① 영상 시장 | 최근 90일 한국에서 이 행동으로 터진 영상은? 어떤 포맷·문형으로? | 영상표(제목·채널·구독자·조회·**채널 평균 대비 배수**·공개일·**포맷 분류**·링크), 문형 패턴, 항목 구성 비교(설명란 타임스탬프), 경쟁 공백 |
| ② 연구 | 이 행동의 의미를 말해 주는 1차 연구는? 반박된 통념은? | 연구표(저자·연도·저널·**국가·기관**·표본·측정 방식·결과 방향·한계·**등급**·원문 URL) |
| ③ 뉴스·통계 | 국내 수치·시의성 이슈는? | 수치표(값·조사 기관·연도·표본·URL), 최근 뉴스 3~5건 |
| ④ 시청자 언어 | 보호자는 이 고민을 어떤 말로 하나? | 댓글·질문글 입말 목록(그대로 인용), 반복 고민 Top 5, 오해(통념) 목록 |

**포맷 분류는 트랙 ①의 핵심이다.** 같은 27만이라도 방송 클립(67분, 출연자 효과)·카드형 쇼츠(8초)·심리 롱폼(8~12분)은 다른 시장이다. 영상마다 `롱폼-심리채널 / 롱폼-방송클립 / 롱폼-수의사·훈련사 / 쇼츠-카드형 / 쇼츠-스토리 / 사연·구조` 중 하나를 붙이고, **우리 포맷(롱폼-심리채널, 쇼츠-카드형·5블록)의 근거와 그 밖의 "수요 신호"를 분리해서** 보고한다.

**우리 채널 영상은 경쟁에서 빼되 참고로 표기**한다(채널 ID `UCe5nZhgg5cjwtU0nDpuf0Bw`). 우리 영상이 검색 상위에 뜨면 그 자체가 정보다.

### 5. 종합 판정 — 채널 필터

`references/channel-filters.md`를 펴고 아래를 판정한다. 각 항목은 근거 한 줄과 함께 ✓/△/✗.

1. **수요** — 우리 포맷에서 최근 90일 채널 평균 대비 ×3 이상 영상이 있나. 다른 포맷에만 있으면 △("수요 신호, 포맷 미검증").
2. **근거** — ✅ 또는 ⚠️ 연구가 소재 핵심 주장마다 1개 이상 있나. 🔍뿐이면 △, 반박됨(❌)이 핵심이면 ✗.
3. **경쟁 공백** — 기존 상위 영상이 다루지 않은 각도·항목이 있나(설명란 목차 비교로 판정).
4. **소재 축** — 수면·잠자리 / 아픔·죽음 신호 / 보호자 실수·금지 / 사랑 확인 / 호기심형 / 기타. 호기심형은 롱폼 ✗ → 쇼츠 큐.
5. **재탕** — 우리 채널 최근 90일 영상 목록을 vidIQ로 직접 불러와 같은 행동이 있는지 본다(5만↑ 같은 행동 = ✗, 5만↓ 겹침 = △).
6. **금지 프레임** — 조사에서 나온 통념·경쟁 영상 주장 중 채널 금지 프레임(pack·dominance·굴 본능·옥시토신 과장·따라다님=분리불안 등)에 해당하는 것을 표시한다. 이건 "쓰면 안 되는 것"이자 처형 구간 재료다.
7. **우리 자산** — 소망이·사랑이 실화, 집에서 직접 미용, 팩트 검증 차별점 중 무엇을 쓸 수 있나.

### 6. 포맷별 산출 (리포트 본문 마지막 절)

- **롱폼**: 항목 후보 **8~10개**(7항목형을 고를 여유분). 각 항목에 [행동 장면 한 줄 → 심리 설명 → 해결 행동] 초안 + 근거 출처 + 등급. 통념 처형 후보(항목당 1개)와 "검색하면 나오는 나쁜 조언" 처형 후보 1개(근거 확보된 것만).
- **쇼츠(5블록)**: 오답 필터 양식(`dog-psych-shorts/references/02_recipe.md` §0) — 통념 / 실제 / 오답 2개 + 반박 근거 / 출처 3개+. 오답 2개가 안 나오면 "쇼츠 부적합"으로 명시.
- **카드형**: 0-1 판정 3문(집에서 보이는 장면인가 / 한 줄로 끝나나 / 근거가 배경에 머무나)과 8칸 후보.
- 포맷 "미정"이면 세 개 모두를 짧게 내고 적합도를 비교한다.

추천은 하되 결정은 하지 않는다: "추천 상위 3 + 이유 한 줄"까지만.

### 6-1. 원문 대조 (대본 완성 뒤, 녹음 전)

이 스킬의 조사 결과로 대본이 써지면, 대본의 🔍 문장을 `references/original-check.md` §2 절차로 원문과 대조한다. 판정·교체 문장·원문 인용을 남기고 대본을 고친다.

### 7. 저장 · 보고

1. 리포트를 `references/report-template.md` 양식으로 작성한다.
2. **구글 드라이브에 Google 문서로 저장**한다(Google Drive 커넥터의 파일 생성 도구, 문서 형식). 파일명: `소재조사_YYYY-MM-DD_<소재 짧은 이름>`. 드라이브 커넥터가 없으면 작업 디렉터리에 `.md`로 저장하고 그 사실을 알린다 — 세션 작업공간은 사라지므로 드라이브 저장을 빠뜨리지 않는다.
   - **드라이브 문서에서는 🔍 같은 4바이트 이모지가 깨진다**(마크다운 → Google 문서 변환 시 「ð」로 표시됨, 2026-10-12 실측). 드라이브본에서는 등급을 글자로 쓴다: ✅→[원문확인] · 🔍ᵃ→[초록확인] · 🔍→[미확인] · ❌→[반박됨]. ⚠️·✓·△·★는 정상 표시된다. 맨 위에 등급 범례 한 줄을 둔다.
   - 드라이브 도구는 이미 만든 문서의 내용을 고칠 수 없다(제목·위치만 변경). 올리기 전에 변환 규칙을 먼저 적용한다. 잘못 올렸으면 고친 본을 새로 만들고, 구버전 처리(휴지통·이름 변경)는 사용자에게 묻는다.
   - 트랙 원자료 전문이 길면(수십 KB) 드라이브 문서에는 요약·판정·포맷별 산출만 담고, 원자료는 레포(`research/<날짜>_<소재>/`)에 커밋한 뒤 링크한다.
3. 채팅에는 **요약 5~8줄 + 드라이브 링크**만 낸다. 리포트 전문을 채팅에 붙이지 않는다.
4. 다음 단계를 안내하고 멈춘다: 롱폼이면 "2단계(구조 설계)로 넘어갈까요?", 쇼츠면 "대본 작성으로 넘어갈까요?".

## 정직성 규칙

조사 리포트는 대본보다 앞서 쓰이므로 여기서 틀리면 뒤 단계가 전부 틀린다.

- **원문 URL이 없는 연구는 ✅를 주지 않는다.** 초록이라도 열어 본 것만 ✅/⚠️. 기억이나 2차 인용(블로그·경쟁 영상 설명란)에서 온 것은 🔍로 두고 "원문 미확인"이라고 쓴다. 경쟁 영상 설명란의 참고문헌은 찾기 출발점일 뿐 근거가 아니다(벤치 채널이 틀린 귀속을 그대로 반복한 사례가 있다 — fact-check-rules.md).
- **기관명에는 국가를 붙이고**, 결과의 방향·측정 방식(소변/혈액/행동 관찰/설문)을 원문대로 적는다.
- **vidIQ 숫자는 그대로 옮긴다.** 반올림은 "약"을 붙인다. 검색 표본이 전수가 아님을 리포트 한계 절에 적는다.
- 조사가 얇게 나온 트랙은 얇다고 쓴다. 빈칸을 추정으로 메우지 않는다.
- **원문을 열 수 없는 환경이 있다.** 클라우드 세션의 네트워크 정책에 따라 WebFetch·curl이 학술 사이트(pubmed, doi.org, KCI, RISS 등)에서 막힐 수 있다(2026-10-12 실측: 전부 차단 — 허용 방법은 `references/original-check.md` §1). 그때는 ✅를 주지 말고, 검색 결과에 초록 문구가 그대로 보인 것만 🔍ᵃ(초록 확인, 원문 미열람)로 구분한다. 리포트 맨 위에 차단 사실을 쓰고, 녹음 전에 대조할 "원문 대조 Top N" 목록을 남긴다. 사용자에게는 환경 설정에서 해당 도메인을 허용하거나 PDF를 올려 달라고 한 줄로 안내한다.

## 비용 감각

vidIQ는 호출당 약 5크레딧이다. 기본 예산은 **트랙 ① 8~12회 + 트랙 ④ 2~3회**. 시작 전에 잔여 크레딧을 확인할 수 있으면 확인하고, 20회를 넘길 것 같으면 먼저 알린다.
