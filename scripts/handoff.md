## 2. 확정 사항

- **제목:** 엄마 곁을 내주는 강아지의 심리 (작은 아이가 보내는 메시지)
- **썸네일 문구:** 자리를 내주는 강아지의 심리 / 단순한 양보가 아닙니다
- **썸네일 구도:** 2층 구도 — 소파 위 엄마 오른쪽에서 큰 아이가 엄마 다리에 머리를 대고 누움, 마루의 작은 아이가 올려다봄. 엄마는 무릎·손만(얼굴 없음). 썸네일에 보호자 단어 금지라 「엄마」는 제목에만.
- **형식:** 서사형 · A 기록편(열린 결말). 채널 첫 서사형. 109만 편(실천심리학 「함께 자는 반려견의 심리」, 46yJzSIvU1E)의 구조를 참고하되 화자는 아빠 1인칭.
- **화자·호칭:** 아빠(「저」). 오프닝에서 사랑이·소망이 이름을 알린 뒤 「큰 아이 / 작은 아이」.
- **말투:** 아빠가 장면을 직접 설명한 말투를 「~합니다」로. 한 문장 30~40자, 꾸밈말·비유 최소. 문학적 묘사·감성 어투는 사용자가 어색하다고 해서 쓰지 않는다.
- **근거 서술:** 누가(나라·대학) → 어떻게 쟀나 → 결과 → 우리 집에 대입. 원문 확인된 것만. 남은 근거 4개: Miklósi 2003(개 vs 늑대 돌아보기) · Maren 2013(공포 조건화, **사람 램프 실험**만 사용) · Gácsi 2013(보호자 곁 심박) · Merck 수의 매뉴얼(관심 끌기 짖음 vs 불안 행동) + 공격성 사다리(BSAVA, PMC 2차 확인).
- **분량 기준(실측):** 직전 7가지 편 자막 4,451자(공백 포함)·3,519자(공백 제외) = 10분 50초 → 공백 포함 411자/분, 공백 제외 325자/분. 스킬의 「320자/분」은 **공백 제외** 기준. 이번 편 TTS 원본은 3,106자(공백 포함)=5분 56초 → 523자/분. 편집 후 길이는 TTS 원본의 약 1.3배.
  - 확정본: 공백 포함 4,247자 · 공백 제외 3,278자 → TTS 원본 약 8분, 편집 후 약 10분 전후 예상.

## 3. 사실 관계 (대본에 쓰인 실제 정보)

- 큰 아이 사랑이: 푸들 남아, 11살. 2015년 여름 네이버 유기견 입양 카페에서 사진으로 처음 봄 → 입양 신청·심사·승인 → 동물병원에서 첫 만남(주위를 뱅글뱅글 돎).
- 작은 아이 소망이: 9살. 2017년 가정에서 태어나 아가 때 옴.
- 엄마·아빠 모두 오른손잡이. 두 아이 모두 엄마 **오른쪽** 선호. 큰 아이 없으면 작은 아이도 오른쪽.
- 소파 장면: 큰 아이가 엄마 앞까지 와서 작은 아이 앞에 멈춰 서면 작은 아이가 바로 마루로 내려감 → 「으~응, 으~응」 → 「멍멍」 반복. 엄마가 빈자리를 가리켜도 안 올라옴. 아빠가 두 아이 사이에 서면 **왼쪽**에 잠깐 앉았다가 금방 내려감.
- 침대: 작은 아이는 엄마 얼굴 근처, 큰 아이는 엄마 다리 근처(자리가 따로 있음). 그래도 작은 아이는 혼자 못 올라가고 짖음. 밤에 캔넬에서 엎드려 자는 날이 많음(매일은 아님).
- 발톱 사건: 작은 아이가 소파에서 엄마 아빠 다리 위를 뛰다 발톱으로 엄마 다리를 찍음 → 엄마 「아야」 → 큰 아이가 입 벌리고 코로 찍으며 짖음(물지 않음) → 작은 아이 납작 엎드림. 침대에서 엄마 손을 찍었을 때도 같음. 몇 번 있었음. 평소 두 아이 사이는 나쁘지 않음. 큰 아이는 엄마 소리에 반응해 움직인 것으로 보임.
- 건강: 잘 자고 잘 먹고 산책 활발, 밤에 깨서 돌아다니는 일 많지 않음. 행동 전문가 상담 계획 없음. 발톱은 다듬지 않음.
- 오른손잡이 → 오른쪽 선호는 **가족의 짐작**(대본도 「~인지도 모릅니다」). 「무서웠던 기억」도 아빠의 해석(「제가 보기엔 … 것 같습니다」 + 자막 「보호자의 관찰과 해석이에요」).

## 4. 대본 수정 이력에서 지켜야 할 결정

- 쥐 실험 인용 금지(혐오감) → 같은 논문의 사람 램프 실험으로 교체.
- Kubinyi & Wallis 2019(다견 가정 설문) 삭제 — 「대장」 인식 설문이라 서열 반박 맥락과 안 맞고, 축약 과정에서 원문과 어긋났음.
- 「아직 답을 찾고 있습니다」류(부족함을 드러내는 말) 금지 → 「지켜보는 중입니다」.
- 「엄마 관심을 받고 싶어서」 → 「엄마의 주의를 더 끌고 싶어서」.
- 큰 아이가 공격적으로 보이지 않게 한 줄 유지(「평소 두 아이 사이는 나쁘지 않습니다…」). 「치안 행동」「엄마를 지키려고」 같은 표현은 쓰지 않음.
- 발톱 장면은 극적으로 다시 쓰지 않음(「달려들었다」 금지).
- 오른쪽 자리 단락은 「두 아이」 바로 뒤에 배치(배경 설명). 훅은 「저희 손과 몇 번의 작은 사건」 두 가지 궁금증.
- 한계 발언은 나레이션 금지, 자막으로. 「보호자님」 4회.
- 분량을 억지로 늘리지 않는다(시청자 지적 이력). 모자라면 실화·근거를 늘린다.
